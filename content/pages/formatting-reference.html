Formatting reference

Jul 8, 2026 meta

This is a demo article showing everything the .article-content class styles automatically. Copy articles/template.html to start a real post — this page is just a cheat sheet.

Paragraphs get generous line height and bold, italic, and linked text all fall out of normal HTML — no extra markup needed.

Subheadings

Use <h3> for section breaks within a post. They get their own spacing rhythm so long articles stay easy to scan.

Blockquotes pick up a large hanging quotation mark instead of a box or a ruled line — for pulled quotes or asides worth setting apart from the main text.

  • Plain <ul> and <ol> lists work as expected.
  • Inline code and full code blocks are both styled.
  • Tags like this — or asmanyasyou-like — just need <a class="tag" href="/tags.html?t=..."> chips inside a <span class="tags"> in the meta line. Clicking one lists every post/article sharing that tag.
